## 4. 核心视觉原则（v2.0 新增）

### 4.1 渐变优先 (Gradient First)
> **禁止大面积使用纯色块**，所有装饰性色块必须使用渐变填充：
- **左上装饰条**：深蓝 `#0B5395` → 亮蓝 `#00B0F0`（水平渐变）
- **标题下划线**：亮蓝 `#00B0F0` → 青色 `#00C9D2`（水平渐变）
- **页脚背景条**：深灰蓝 `#1A3F5E` → 中灰蓝 `#2C5F8A`（水平渐变）
- **章节编号**：深蓝 → 科技蓝 渐变
- **圆形编号**：科技蓝 `#0F6DFF` → 亮蓝 `#00B0F0`（径向/角度渐变）
- **表格表头**：深蓝 `#0B5395` → 科技蓝 `#0F6DFF`（垂直渐变）
- **封面右侧背景**：深蓝 → 亮蓝（水平渐变，替代纯色图片区）
- **结束页背景**：白 `#FFFFFF` → 浅蓝 `#B3DDF2`（垂直渐变）

### 4.2 卡片式布局 (Card Layout)
> 所有内容区域使用**圆角矩形卡片**作为背景：
- 卡片填充：白色 `#FFFFFF`
- 卡片边框：浅蓝 `#B3DDF2`，线宽 0.5pt
- 圆角半径： adjustments[0] = 0.05（约 5% 圆角）
- 卡片边距：内容距卡片边缘至少 0.15 英寸
- **适用页面**：标准文本页、双栏对比页、产品展示页、表格页、案例页

### 4.3 精致页脚 (Refined Footer) - v3.0
- **高度**：0.35 英寸
- **顶部装饰**：页脚上方增加 1.5pt 亮蓝细线作为分隔
- **背景**：渐变填充（深灰蓝 → 中灰蓝）
- **三栏布局**：
  - 左侧：`Universal-PC Technology Development Co., Ltd`（9pt，Arial，白色）
  - 中间：`面向客户，服务客户，依托客户`（10pt，微软雅黑，白色）
  - 右侧：`Page X` + `当天日期`（10pt，Arial，白色）
- **适用范围**：除封面和结束页外的所有页面

### 4.4 层次与留白 (Layer & Whitespace)
- **安全边距**：左右 0.3 英寸，顶部标题区 0.45 英寸
- **内容间距**：段落间距 ≥ 1.5 倍行距
- **几何装饰叠层**：章节分隔页使用多层几何图形（三角形 + 矩形 + 白色条带）创造深度
- **半透明遮罩**：封面左右分界处使用白色半透明渐变遮罩，使过渡自然

## 7. 渐变实现参考 (python-pptx)

```python
# 水平渐变矩形
shape = slide.shapes.add_shape(MSO_SHAPE.RECTANGLE, left, top, width, height)
fill = shape.fill
fill.gradient()
fill.gradient_angle = 0  # 0=水平, 90=垂直
fill.gradient_stops[0].color.rgb = color1
fill.gradient_stops[1].color.rgb = color2
shape.line.fill.background()

# 径向渐变圆形
circle = slide.shapes.add_shape(MSO_SHAPE.OVAL, left, top, width, height)
fill = circle.fill
fill.gradient()
fill.gradient_angle = 45
fill.gradient_stops[0].color.rgb = color1
fill.gradient_stops[1].color.rgb = color2

# 圆角矩形（卡片）
card = slide.shapes.add_shape(MSO_SHAPE.ROUNDED_RECTANGLE, left, top, width, height)
card.fill.solid()
card.fill.fore_color.rgb = WHITE
card.line.color.rgb = LIGHT_BLUE
card.line.width = Pt(0.5)
card.adjustments[0] = 0.05  # 5% 圆角
```
